# SIMPLEST BASEBALL

ブラウザだけで動く、HTML/CSS/JavaScript製のシンプルな2D野球ゲームです。

## 起動方法

`index.html` をブラウザで開くと起動します。ローカルサーバーは必須ではありません。

## バグ確認

JavaScriptを修正したあとは、起動、試合開始、基本判定、守備描画が止まらないかをまとめて確認できます。

```powershell
powershell -ExecutionPolicy Bypass -File tests/run-smoke.ps1
```

Node.jsが使える環境では直接実行しても構いません。

```bash
node tests/smoke.js
node tests/static-checks.js
```

通常の `node` が見つからない場合、`tests/run-smoke.ps1` はCodex同梱のNode.jsも探します。

## 主なファイル

- `index.html`: ゲーム画面、開始メニュー、選手選択UI
- `style.css`: 画面レイアウトとメニューの見た目
- `script.js`: ゲーム進行、投球、打撃、守備、走塁、音声処理
- `tests/smoke.js`: 最低限の自動チェック
- `tests/static-checks.js`: HTMLとJavaScriptの接続、文字化け、構文チェック
- `assets/`: 選手スプライト画像
- `audio/`: 効果音とBGM

## 操作

- 投球: `5` 直球 / `8` 遅い球 / `2` 速球 / `0` 決め球
- 投手位置: `7` / `9` で投手の立ち位置を移動
- 投球後の変化: `4` / `6` で左右変化
- 投球後の速度: `1` / `3` で減速 / 加速
- 打者: マウス移動、左クリックでスイング
- 共通: `Enter` 次の投球 / `R` メニューへ / `O` 1人用 / `T` 2人用

## 5人守備ルール

通常の9人制ではなく、`P` / `SS` / `2B` / `L` / `C` / `R` を使った少人数のミニ野球です。

- `P`: 投手前や弱いゴロを処理
- `SS`: 三遊間寄りの打球を処理
- `2B`: 一二塁間寄りの打球を処理
- `L`: 左方向の外野打球を処理
- `C`: 中央方向の外野打球を処理
- `R`: 右方向の外野打球を処理

守備画面では、落下地点または通過地点に最も対応しやすい選手が自動で走ります。スピード、守備力、肩、役割補正によって、処理、アウト、ヒット、二塁打、三塁打、ホームランの結果が変わります。

## 得点

- ヒット: 1点
- 二塁打: 2点
- 三塁打: 3点
- ホームラン: 4点
- 四球 / デッドボール: 押し出し時のみ1点

## 修正メモ

- まず `tests/run-smoke.ps1` を実行して、既存の動きが壊れていないか確認します。
- 表示文言を変更したあとは、`tests/static-checks.js` が文字化けと壊れたタグを検出します。
- `script.js` は大きいので、調整値は上部の `*Tuning` 定数群を優先して触ると影響範囲を追いやすいです。
- 日本語テキストはUTF-8で保存してください。文字コードがずれると、表示文言だけでなくHTMLタグやJavaScript文字列も壊れることがあります。
